# 发布前验收记录

日期：2026-10-23。基线为已合并 PR #2 的 `227dbbd`，本轮分支 `codex/release-readiness`。首发方向为 Mac App Store；尚无 Apple Developer 会员。本文记录本地证据与待完成门槛，不是上线许可。

## 环境和隔离

- 本机：Apple M3 Pro，macOS 15.7.3（24G419），Xcode 16.4（16F6）。只有一块内建显示器，逻辑分辨率 1512 × 982、120 Hz。
- 单元测试宿主跳过生产启动；统计使用唯一 UserDefaults suite、注入时钟/时区。显示测试只创建未显示的原生窗口，不改变系统显示器、VoiceOver、Reduce Motion、时区或睡眠状态。
- 原生交互验收使用独立 Bundle ID `Yvette.LumenFocus.StoreReadinessReview` 和最终复测副本 `Yvette.LumenFocus.StoreReadinessFinal`，Release 配置、生产界面代码及本机 ad-hoc 签名。签名中只有 App Sandbox 与用户选中文件读写权限；独立沙盒容器实际生成。没有启动正式身份应用或改动其偏好。
- 正式产物保持 `Yvette.LumenFocus`；当前版本仍为 1.0（1），未创建 tag、GitHub Release 或商店上传。

## 运行开销

初始副本关闭设置与统计窗口、继续后台计时后，每 5 秒读取一次同一进程的累计 CPU 时间和 RSS，共 25 次、120.51 秒。CPU 增量 4.07 秒，相当于平均 **3.38% 单核 CPU**；RSS 为 **42.84–50.53 MiB**。采用累计 CPU 差值除以实际单调时钟时长，未用瞬时 `%cpu` 代替区间平均。

随后 5 秒调用栈采样仍出现隐藏 `SettingsView`、`MenuBarPopoverView` 的布局，以及重复菜单图标/tooltip 更新，因此本轮收敛关闭窗口的视图生命周期和同一轮状态发布的重复刷新。

优化后的 Release 沙盒副本重复打开设置/统计、休息后取消、导出、关闭并重开窗口，再全部关闭继续计时；按同样方法采样 25 次、120.27 秒。CPU 增量 **0.62 秒**，平均 **0.52% 单核 CPU**；RSS **42.91–50.39 MiB**。这两次样本显示后台 CPU 从约 3.38% 降至 0.52%，内存区间接近，没有据此声称内存占用显著下降。采样早于收尾的弹层初始尺寸补丁，未作为该补丁后或实际弹层反复使用后的性能证明。原始 JSON 保存在本次本机临时目录 `lumen-store-resource-sample.json` 与 `lumen-store-final-resource-sample.json`。

这是单台设备的短时观察，不是 Energy Log、功耗测量、长期泄漏证明或性能承诺。构建/界面自动化及系统其他负载可能影响结果；正式候选版还需连续工作日和重复开关窗口的长期采样。

## 尚未完成的发布门槛

- 多屏：外屏在左/右/上/下、不同缩放，休息各阶段插拔主/副屏；全程可退出，保留屏幕不重新渐暗、不抢回已切走的焦点。
- Spaces/全屏：在原生全屏应用、不同 Space 和多屏各自 Space 下确认覆盖、退出、焦点返回与轻提醒行为。
- 物理锁屏/睡眠：工作与休息各阶段锁屏/合盖/唤醒；无锁屏时间计入工作，无旧罩层/重复完成，短离开和足够长自然休息符合规则。
- 可访问性：实际 VoiceOver、完整键盘导航、系统 Reduce Motion；英文/中文、浅色/深色及设置 520 × 480、统计 640 × 500 最小窗口的完整逐项走查。
- 平台与能耗：macOS 13、Intel 实机；完整工作日、休眠循环、反复开关窗口的 CPU、唤醒次数与内存趋势。
- 账号和分发：开发者会员、真实 Team/Bundle ID、商店签名和 provisioning、Organizer Validate/Distribute、App Store Connect 处理与 TestFlight。
- 正式沙盒：商店签名下全局快捷键、前台规则、登录项、CSV 保存/取消/覆盖/失败、升级保留设置和统计；所有隐私/支持 URL 上线可达。
- 商店材料：最终真实截图、名称可用性、价格/地区/年龄分级、版权/审核联系人、隐私问卷及账号协议由持有人确认。

没有这些设备或账号时保持“待验收”，不以 mock、构建成功或本机临时签名标记通过。操作步骤见 [App Store 准备](app-store-readiness.md)，重复检查命令见 [构建检查](release-build.md)。
