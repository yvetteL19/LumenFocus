# P0 与核心流程重构验收记录

日期：2026-10-22。范围为周期可靠性、休息控制、统计一致性、首次使用与设置体验。收费、授权和发行工程不在本轮实现中。

## 已交付

| 原问题 | 当前行为 |
|---|---|
| 多个计时来源与旧恢复回调冲突 | `CycleEngine` 统一截止时间，主线程 heartbeat 只驱动观察；暂停不依赖迟到回调 |
| 20 秒预设实际是分钟、过渡侵占休息 | 秒级配置和旧值迁移；实际休息加独立 2/1 秒过渡 |
| 延后可能变成重开整个工作周期 | 未到点延长原有效期限；已到点/休息中从现在延后指定时长 |
| 取消、跳过、完成混为一谈 | 取消保留期限并至少缓冲 5 分钟；跳过重开一轮；只有完成记次数 |
| 规则与暂停互相覆盖 | 环境限制与手动暂停独立，恢复至少缓冲 60 秒 |
| 无输入被当作休息、会议被当作离屏 | 无输入只降级轻提醒，应用避让仍计工作；锁屏睡眠暂停计时 |
| 打开自身面板解除会议规则 | 记住最近外部应用；自身 UI 激活不撤销原规则 |
| 休息中鼠标出口消失、多屏坐标混用 | 每屏本地 bounds，全程结束/延后/Esc；退出恢复原应用焦点 |
| 设置刚改完立即开始使用旧时长 | 开始休息时原子应用最新配置；专门回归用例覆盖 |
| 旧数据双写与日期边界 | 单一仓库、午夜分摊、UUID 去重、按字段最大值迁移、真实 90 天保留 |
| 英文引导裁切、空白原生设置页 | 可滚动引导与固定导航，原生菜单和菜单栏共用设置窗口 |

默认采用不激活应用的轻提醒。沉浸渐暗需主动选择。默认休息提示用户看向屏幕之外，未展示无素材音频、未接入 Widget 或健康达标结果。旧版重复周报已清除。

## 自动化验证

Xcode 16.4、macOS 15.7.3、Apple Silicon 本机运行。测试使用独立时钟和 UUID UserDefaults suite，测试宿主跳过生产应用启动副作用。

- 周期 18 项：延后/取消/暂停/跳过、环境组合、长短睡眠、稳定时间与系统时间修改、迟到心跳、配置变更及快速开始。
- 应用规则 4 项：外部规则应用、自身界面、其他外部应用与运行时开关。
- 展示适配 3 项：阶段、全程取消和延后、非完成中断。
- 设置 6 项：迁移、秒级持久化、边界、规则保存及重置。
- 统计 14 项：持久化、迁移去重、日界线/夏令时、小数秒、缓存落盘、保留、时间回拨和损坏恢复。

共享 scheme 可运行全部 45 项。GitHub Actions 在 PR 和 main 上执行同一套测试，以及 arm64/x86_64 通用无签名 Release 构建。PR 检查是每个提交对应的最终结果来源。

## 本机交互检查

用独立 Bundle ID 的临时构建进行，未更改正式安装的偏好和记录：

- 英文欢迎、跳过演示、节奏和模式选择；自定义内容能滚动且底部导航可见。
- 20 秒设置可保存；设置页明确展示轻提醒及可选开机启动。
- 原生 `⌘,` 可直接打开完整设置页。
- 正式遮罩使用简短离屏提示；超过 5 秒后按钮仍可见，Esc 能提前结束。
- 20 秒休息自动撤罩；此前取消的一次没有增加完成数，实际完成的一次计为 1。
- 统计图表及完成数显示正常。发现的英文窗口标题与单数显示问题已修正。

读取纯菜单栏弹层时，当前 UI 自动化工具存在可观测性限制。进程采样和设置窗口验证确认应用正常运行；未把工具超时当作应用崩溃。全局 Carbon 快捷键的真实物理输入、轻提醒不抢焦点及外部应用焦点恢复仍需人工验收。
