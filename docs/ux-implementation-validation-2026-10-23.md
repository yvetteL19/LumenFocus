# 新用户体验重构与验收

> **历史记录 · Superseded（2026-10-24）**：本文保留当时的评审或验收证据。默认轻提醒、应用避让、无操作检测与完成导向的产品建议已被用户纠偏取代；现行目标与行为以 [产品契约](product-contract.md) 为准。下列测试数量和设备结果不能证明本轮新交互已经验收。

日期：2026-10-23 至 2026-10-24。基线：PR #3 合并后的 `6e53f44`。对应评审：[新用户旅程与 UI/UX 评审](ux-journey-review-2026-10-23.md)。

## 落地范围

- 首次启动压缩为一页，节奏按需展开；只有“开始提醒”提交草稿。退出设置不会偷偷采用默认节奏，登录启动仍由用户选择。
- 开始前显示休息时长和渐暗后果；所有入口统一“提前结束”和默认延后 5 分钟。菜单提供结果反馈与下一次时间，不增加完成弹窗。
- 设置分为提醒、提醒避让、通用。避让名单来自实际规则定义；无操作规则只在自动渐暗模式出现。
- 菜单删除重复信息；休息画面突出远望指令；记录页保留两项摘要、趋势，折叠每日明细和解释。新增原生应用菜单入口及 ⌘1/⌘2 快捷键。
- 提供英、中、日、法资源和复数规则，共 350 个资源键。首次默认跟随系统，英语为开发/回退语言。地区、时区和小时制仍遵循用户设置。
- 共享时长选择器、动作策略、时间格式、应用名单和语义颜色；删除无引用的呼吸圆点、远望圆点和旧提示集合。

## 实际走查

先在独立 Bundle ID `Yvette.LumenFocus.JourneyRefinement` 中走查，再使用最终通用 Release 的独立沙盒副本 `Yvette.LumenFocus.JourneyFinal` 复验，未修改正式应用的偏好或记录。使用当前 Mac 的单屏、浅色外观。

| 任务 | 实际观察 |
| --- | --- |
| 英语首次启动 | 一页显示用途、节奏摘要、提醒方式、渐暗预览和可选登录启动 |
| 改节奏并开始 | 选择 20 分钟 / 20 秒，开始后在设置中确认两项均保存，重现旧问题的路径现已通过 |
| 自然结束 | 真实等待 20 秒休息结束，返回原窗口；随后法语菜单和记录页均显示 1 次完整休息 |
| 提前结束 | 法语“Terminer plus tôt”退出；记录保持 1 次，菜单明确显示提前结束未计入完成 |
| 暂停与恢复 | 法语菜单显示 15 分钟/1 小时的目标时间；暂停后主操作变成恢复，手动恢复可继续休息 |
| 提醒避让 | 英语界面展开实际支持应用名单；轻提醒模式下隐藏无操作规则 |
| 语言待应用 | 未改语言时无重启按钮，选择法语后才显示应用操作 |

实际走查发现并修复了两个仅靠资源/模型测试不能发现的问题：法语记录页固定宽度的分段控件溢出；沙盒会忽略 `NSWorkspace.OpenConfiguration.arguments`，导致语言重启无法返回设置且进程交接失效。最终构建复验结果：

- 编辑 20 分钟 / 20 秒后选择“稍后设置并退出”，再次打开仍显示未完成引导及原先 40 分钟 / 5 分钟；重新编辑并提交才保存 20 分钟 / 20 秒。
- 英语真实完成 20 秒休息后，记录页显示 `1 completed break`。
- 英语 → 法语 → 日语 → 简体中文逐次选择并重启，每次均直接返回对应语言的“通用”页，且重启按钮消失。法语记录仍为 `1 pause terminée`，已保存工作时长继续增长。
- 法语记录页的分段控件保持在页边距内，不再向左溢出；日语提醒页的长标签、说明与按钮正常显示。
- 日语启动休息后用 Esc 提前结束，记录仍为 1 次。
- 中文启动休息并选择“5 分钟后再提醒”，菜单显示新的目标时间及“已延后提醒”，仍为 1 次完成。⌘1 可从其他应用窗口转到提醒面板。
