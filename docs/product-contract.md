# LumenFocus 产品契约

生效：2026-10-24。来源：用户对本人实际使用目标的明确纠偏。此文件取代先前“默认轻提醒、应用避让、完成导向”的产品判断；历史评审和验收仅说明当时版本。以下是当前实现必须遵守的行为，不代表已经完成设备或发行验收。

## 要解决的问题

用户投入工作后容易忘记时间，普通通知可能完全没有被注意到。LumenFocus 要提供一个自动、明显、无声且容易退出的休息提醒，而不是替用户判断哪些应用更重要。

到点时，用渐暗的屏幕提醒“休息一下”。用户可以看看窗外、伸展身体、喝水，也可以立刻返回工作。不以“完成”“达标”“坚持”评价选择，不要求先点击一张提醒卡片才能看到遮罩。

## 唯一的提醒流程

1. 用户设定提醒间隔和休息时长，开启提醒。
2. 到点后，各显示器自动渐暗，不播放声音，不先弹轻提醒。
3. 遮罩提供简短休息建议；剩余时间只是次要信息。
4. 任意键（包括 Esc）或“返回工作”立即退出遮罩。触发退出的按键由遮罩处理，不转发或重放给底层应用。
5. 没有操作时，达到设定休息时长后自动渐亮、返回原有任务。
6. 返回后按完整提醒间隔重新计时，不在几分钟后反复催促。

遮罩只改变提醒呈现。它不暂停、静音、关闭、操纵或重新启动其他应用，也不发送播放/暂停媒体命令。底层视频、会议、下载和计算任务照常运行。

## 用户控制

| 操作 | 行为 |
| --- | --- |
| 开启提醒 | 从当前时刻计算完整提醒间隔；到点自动渐暗。 |
| 停止提醒 | 关闭遮罩，停止提醒和工作计时。停止状态保留到下次启动，只有用户重新开启才恢复。 |
| 跳过本次 | 放过这一次，从当前时刻重新计算完整提醒间隔。 |
| 返回工作 / 任意键 | 立即关闭当前遮罩，重新计算完整提醒间隔，不显示“未完成”或“不计数”提示。 |
| 暂停 | 在指定截止时间之前不渐暗；暂停期间工作计时继续。提供 1 / 2 / 4 小时和自定义 1–1440 整数分钟。截止时间保留到下次启动。 |
| 暂停到期 / 恢复提醒 | 从恢复时刻重新计算完整提醒间隔，不立刻补发一个过期提醒。 |
| 预览 | 用户主动查看渐暗效果，可随时返回；不改变正式提醒状态或历史记录。 |

停止或暂停时，不提供会暗中结束停止/暂停的“现在休息”入口。设置的变化以及恢复默认设置不能偷偷重新开启提醒或清除暂停。首次启动采用当前设置确认流程；未确认时不默认替用户开始计时。

## 不提供的判断与功能

- 不根据前台应用、会议、视频、全屏播放或输入空闲情况延迟提醒。
- 不识别真实通话、屏幕共享、观看内容、注意力、眼睛状态或实际休息。
- 不提供应用名单、例外名单或“智能避让”开关。
- 不提供轻提醒/自动渐暗模式选择。唯一提醒方式是自动无声渐暗。
- 不提供声音选择、强制休息、完成目标、连续打卡、健康评分或主动周报。

用户知道自己需要专注多长时间，可在菜单中主动暂停；产品不再猜测。

## 锁屏和睡眠

锁屏/睡眠是操作系统生命周期事件，不是应用避让。期间停止工作计时并移除遮罩。返回时：离开时间至少达到所设休息时长，则重新计算完整间隔；较短离开保留原期限并给予至少 60 秒缓冲。锁屏或睡眠不自动解除用户的停止或暂停决定。

## 设置、记录与隐私

提醒间隔为 15–120 分钟，默认 40 分钟；休息时长为 20–900 秒，默认 300 秒。渐暗 2 秒、渐亮 1 秒与所设休息时长分开。调整休息时长从下一次休息生效；提醒间隔调整保留本轮已经计时的进度。新交互若改变这些值，必须同步修改契约和回归测试。

偏好与历史记录保存在本机，不上传。历史记录继续使用既有存储格式和 90 天保留策略；原有“完成次数”字段仅指计时自然结束的休息，不是用户表现或休息质量。不得把提前返回的数据重新伪装成过去的完整休息。记录页可中性说明字段口径，主菜单和遮罩不展示完成压力。

统计按固定公历日期键和本地时区归属：时区变化不重写已有日汇总，新活动跟随新时区。缺失日期不导出成真实零记录；CSV 只包含用户选择范围内已有记录。未来日期与损坏数据保留既有恢复保护。

## 文案与可访问性

核心词为“提醒”“休息一下”“返回工作”；不将“离屏休息”作为产品名称或主流程术语。英文对应 reminder / take a break / back to work；日语、法语表达相同操作后果。

所有显示器都保留明确返回按钮，任意键和 Esc 均有效；支持系统减少动态效果。自动提醒不应激活整个应用或打开额外设置/记录窗口。使用本地窗口事件退出，不新增键盘记录、辅助功能或屏幕录制权限。

## 验收边界

应重新验证自动到点、无声渐暗、任意键退出、自然渐亮、停止持久化、暂停到期、跨重启暂停、设置即时生效、多屏/热插拔、Spaces、锁屏/睡眠和中英日法文字。底层任务继续运行、触发键不重放及焦点行为需要真实设备走查。历史测试和验收通过不能替代本轮验证，商业发布门槛保持独立。
