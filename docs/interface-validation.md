# 菜单、设置与统计体验优化验收

日期：2026-10-23。基于已合并的 PR #1；本轮保持周期和统计仓库语义，优化每日使用入口。

## 交付内容

- 菜单将状态、下次提醒、当前节奏与主操作分层；主按钮的点击区域随标签铺满。不足一分钟显示秒数，菜单栏紧凑数字显示 `<1m`。
- 暂停时可恢复、调整截止时间，或主动“休息并恢复提醒”。文案说明主动休息会结束暂停，以及到期后应用规则仍生效；右键菜单保持相同行为。
- 设置分为节奏、勿扰规则、通用、数据与支持。常用休息时长可直接选择，其他时长保留已有值；说明可换行，窗口可缩放并记忆尺寸。
- 统计在最近 7 / 30 / 90 天间切换，摘要、图表、日期明细与 CSV 共享同一范围。缺失日期与真实零值分别呈现；只有真实记录进入 CSV，文件名包含起止日期。
- 统计不再使用难以浏览的固定热力图；原生日列表提供每个日期的完整辅助朗读标签。短于一分钟的已计时工作按秒显示。
- 没有加入账号、网络上传、计费或发行变更；正式 Bundle ID 保持不变。

- 统计回归覆盖所选区间含今天、跨年/闰日、上海日期、洛杉矶夏令时的 23/25 小时日、缺失与零值、活动日、未来/非法日期过滤、摘要和 CSV 一致性。
- 通用无签名 Release：arm64 与 x86_64 构建通过。
- 两种语言的 301 个键一致；变更界面的中文字面量与格式占位符检查通过；`git diff --check` 通过。

- 英文四个设置分组、常用/其他时长展开、原生 `⌘,`、支持页统计入口可用。
- 发现并修复原生 Form 的说明文字换行后靠右对齐，以及菜单主按钮在非活动窗口下白底白字的问题。

- 统计切换 90 天后日期范围与活动日分母同步；有计时但无完成休息的日期显示 0，其余日期显示无记录。

- 将测试构建切换为简体中文并重开；菜单工作/暂停状态、暂停时长选项、设置和统计页均可读。非活动窗口下的主按钮文字已复查可见。
